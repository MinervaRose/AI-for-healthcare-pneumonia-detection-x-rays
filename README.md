# Overview

This project explores the use of deep learning for automated pneumonia detection from chest X-ray images.

The work was completed as part of the AI for Healthcare Nanodegree and focuses not only on image classification but also on the broader clinical AI workflow:

* Medical image exploration
* Dataset analysis
* DICOM validation
* Deep learning model development
* Threshold optimization
* Clinical performance evaluation
* FDA-style validation planning

The project demonstrates how modern computer vision techniques can be applied to medical imaging while acknowledging the regulatory and safety constraints associated with healthcare AI.

# Dataset

The project uses the NIH ChestX-ray14 dataset.

Key characteristics:

* Chest radiographs from adult patients
* Pneumonia and non-pneumonia cases
* Labels derived using NLP from radiology reports
* Significant class imbalance in the original dataset

To mitigate imbalance:

* All pneumonia cases were retained
* Matching non-pneumonia cases were sampled
* Balanced training and validation datasets were created

# Model Architecture

The classifier is based on:

## Backbone

VGG16 (ImageNet pretrained)

## Classification Head

* GlobalAveragePooling2D
* Dropout
* Dense (128 units, ReLU)
* Dropout
* Dense (1 unit, Sigmoid)

The convolutional backbone remained frozen while the custom classification layers were trained.

# DICOM Validation

Before inference, each image is validated using DICOM metadata checks.

Accepted studies must satisfy:

* Modality = DX
* Body Part = CHEST
* View Position = AP or PA

Images failing these checks are rejected before entering the model pipeline.

---

# Data Augmentation

Training images were augmented using:

* Horizontal flips
* Small rotations
* Zoom transformations
* Width shifts
* Height shifts

Augmentation was applied only to training data.

Validation data remained untouched.

---

# Model Evaluation

The project evaluates performance using clinically meaningful metrics:

* Accuracy
* Precision
* Recall
* F1 Score
* Precision–Recall Curve

Threshold optimization was performed to maximize the F1 score rather than relying on the default 0.5 classification threshold.

# Results

Validation performance:

| Metric    | Value |
| --------- | ----- |
| Accuracy  | 0.75  |
| Precision | 0.62  |
| Recall    | 0.83  |
| F1 Score  | 0.71  |

Best classification threshold:

```text
0.49
```

The model prioritizes sensitivity while maintaining reasonable precision, which is often desirable in screening-oriented workflows.
